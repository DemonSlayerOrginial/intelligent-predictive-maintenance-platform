# Streaming model bundle card

## Intended use

Demonstration of end-to-end predictive-maintenance ML engineering on simulated industrial telemetry.

## Outputs

- failure probability within the next 24 logical hours
- anomaly detection signal
- estimated remaining useful life in hours

## Training data

Synthetic telemetry generated by `src.data.generate_synthetic`. The generator models latent wear, load-dependent degradation, maintenance resets, and probabilistic failures.

## Evaluation

Failure classification uses chronological train/validation/test periods. The validation period selects an F2-optimized threshold; the test period is untouched during threshold selection. RUL uses a later chronological holdout.

## Limitations

Synthetic physics are simplified. Estimated probabilities are not calibrated for any real machine. RUL is meaningful only relative to the generator. Model outputs must not be used for real industrial safety decisions without new data, validation, calibration, and domain review.
